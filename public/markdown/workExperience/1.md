#### 스패로우 엔터프라이즈 개발

DevSecOps 구축을 도와주는 웹 기반 Application (상시 업무)

- `Next` 기반의 웹 Application으로, 소프트웨어 **품질/보안 검증 제품의 프론트엔드 전반**을 담당하고 있습니다.
- **SSO / OTP(2FA) 인증 모듈**을 직접 구현하며, 보안에 민감한 로직과 복잡한 비동기 흐름을 설계했습니다.
- **GraphQL 요청 계층을 설계**하고, `React-Query`와 `Zustand`로 **서버 상태와 클라이언트 상태를 명확히 분리**했습니다.
- 금융권 고객사 등 **보안 요구사항이 높은 환경**의 개발 프로세스에 맞춰 제품을 개발하고 있습니다.
- 에러 바운더리 설계를 통해 장애 상황에서도 서비스 전체가 중단되지 않도록 방어했습니다.
- `TypeScript` `React` `Next` `React-Query` `GraphQL` `Emotion.js` `Storybook` `Cursor Agent`

#### 디자인시스템 운영

Atomic design 구조의 디자인시스템 구축 및 운영

- **Atomic design 구조의 디자인시스템**을 구축하고 운영하고 있습니다.
- `Storybook`으로 컴포넌트를 문서화하여, 디자이너/기획자와 **동일한 기준으로 UI를 논의**할 수 있는 환경을 만들었습니다.
- `cva`, `tailwind-merge`, `clsx`를 조합해 **variant 기반의 재사용 가능한 컴포넌트 시스템**을 설계했습니다.
- `BackstopJS` 기반의 **시각적 회귀 테스트를 gitlab-runner 파이프라인에 연동**해, 500여 개의 Storybook story를 자동으로 검증합니다.
- 컴포넌트 설계 원칙과 재사용성을 고려한 UI 아키텍처를 정리해 팀에 공유하고, 컨벤션으로 정착시켰습니다.
- `TypeScript` `React` `Next` `Storybook` `BackstopJS` `Emotion.js` `TailwindCSS`

#### E2E 테스트 구축 및 자동화

Playwright 기반 E2E 테스트 자동화 파이프라인 구축

- `Playwright`로 **모든 서비스 사용 시나리오의 E2E 테스트 자동화 파이프라인**을 구축했습니다.
  - **220개의 테스트 코드**를 작성 및 유지보수하며, **수동 전수 테스트 시간을 75% 단축**했습니다.
- `Docker` + `gitlab-runner`로 **테스트 CI/CD 환경을 구축**하고, 테스트를 제품 관리 프로세스에 정착시켰습니다.
- **MCP(Model Context Protocol) 서버를 직접 설계 및 운영**했습니다.
  - 제품의 기능 명세, 코드 컨벤션, 테스트 시나리오를 컨텍스트로 주입하여, **각 기능 담당자가 AI의 도움을 받아 테스트 코드를 직접 작성하고 디버깅**할 수 있는 환경을 만들었습니다.
- 테스트 작성 가이드를 문서화해, 테스트가 특정 담당자에게 몰리지 않도록 팀 전체로 확산시켰습니다.
- `Playwright` `Docker` `gitlab-runner` `React` `Cursor Agent`

#### Emotion → Tailwind 마이그레이션

디자인시스템 CSS 라이브러리 마이그레이션 (2025. 03 - 2025. 04)

- 디자인시스템의 CSS 라이브러리를 **`Emotion` → `TailwindCSS`로 마이그레이션**하는 작업을 주도했습니다.
- **Claude의 서브 에이전트(Sub-agent) 구조를 활용한 Agent Teams 방식**을 실무에 적용했습니다.
  - '컨벤션 분석 에이전트'가 기존 코드 패턴을 파악하고, 그 결과를 '변환 에이전트'에 전달해 1차 마이그레이션을 수행하는 파이프라인을 구성했습니다.
  - 그 결과, **한 달 분량의 작업을 2주 만에 완료**했습니다.
- `BackstopJS` 시각적 회귀 테스트로 **500여 개의 Storybook story를 자동 검증**하며, UI 변경 없이 안전하게 전환했습니다.
- 마이그레이션 과정과 의사결정을 문서화해 팀에 공유했습니다. (**[관련 글](https://velog.io/@josuncom)**)
- `TypeScript` `React` `TailwindCSS` `Emotion.js` `Storybook` `BackstopJS` `Cursor Agent`

#### app router로의 마이그레이션

page router → app router 부분 마이그레이션

- `page router`로 구현된 제품을 **`app router`로 부분 마이그레이션**했습니다.
- **RSC(서버 컴포넌트)와 클라이언트 컴포넌트의 경계를 설계**하고, **서버 prefetch 구조를 도입**했습니다.
  - 그 결과 **초기 로딩 속도(FCP)를 60% 개선**했습니다.
- 기존 `React-Query` 기반의 데이터 페칭 계층을 서버 컴포넌트 환경에 맞게 재설계했습니다.
- 점진적 전환이 가능하도록 마이그레이션 순서와 기준을 정의하고, 문서로 남겨 팀원들이 동일한 방식으로 작업할 수 있게 했습니다.
- `Codex`를 활용한 **자동 코드 리뷰 프로세스를 구축**해, 전환 과정에서 코드 컨벤션과 잠재적 버그를 검토했습니다.
- `TypeScript` `Next` `RSC` `React-Query` `TailwindCSS` `Cursor Agent`
