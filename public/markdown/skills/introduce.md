**Web**

- 유지보수 비용과 협업 효율을 고려한 **'좋은 코드'** 설계에 집중하며, 단순 기능 구현을 넘어 아키텍처 수준의 의사결정 경험이 있습니다.
- SEO 경험이 있으며, 다양한 모바일 브라우저 환경의 웹뷰 최적화 및 크로스 브라우저 이슈 대응 경험이 많습니다.
- 엔터프라이즈 제품 개발 경험을 통해 금융권 고객사 등 보안 요구사항이 높은 환경에서의 개발 프로세스를 이해하고 있습니다.

**HTML/CSS**

- CSS-in-JS(`styled-components`, `Emotion`)를 실무에서 깊이 사용했으며, **Emotion에서 Tailwind CSS로의 디자인 시스템 마이그레이션을 주도**한 경험이 있습니다.
- `cva`, `tailwind-merge`, `clsx`를 조합해 variant 기반의 재사용 가능한 컴포넌트 시스템을 설계했습니다.
- 다양한 디바이스에서의 반응형 디자인과 복잡한 퍼블리싱 경험이 있습니다.

**JavaScript/TypeScript**

- JavaScript와 TypeScript를 실무에서 깊이 사용하며, 타입 설계를 통해 프로젝트 안정성을 높이는 데 집중합니다.
- ES6+ 문법(`async/await`, `Class`, 구조분해, 옵셔널 체이닝 등)을 자연스럽게 활용하며, 함수형 프로그래밍 패러다임을 실무에 적용한 경험이 있습니다.
- 복잡한 비동기 흐름 처리 및 에러 바운더리 설계 경험이 있으며, 인증 모듈(SSO, OTP) 등 보안에 민감한 로직도 직접 구현했습니다.

**React/Next.js**

- **Storybook 기반 아토믹 디자인 시스템을 구축 및 운영**한 경험이 있으며, 컴포넌트 설계 원칙과 재사용성을 고려한 UI 아키텍처 설계에 익숙합니다.
- React-Query와 Zustand를 함께 사용하며 **서버 상태와 클라이언트 상태를 명확히 분리**한 상태 관리 경험이 있습니다.
- **Next.js Page Router → App Router 마이그레이션을 주도**했으며, RSC(서버 컴포넌트)와 클라이언트 컴포넌트의 경계 설계, 서버 prefetch 구조 설계를 통해 **초기 로딩 속도(FCP)를 60% 개선**한 경험이 있습니다.
- SSO/OTP(2FA) 인증 모듈, GraphQL 요청 계층 설계 등 복잡한 기능의 프론트엔드 아키텍처 설계 경험이 있습니다.

**Testing & DevOps**

- **Playwright를 활용한 E2E 테스트 자동화 파이프라인을 구축**했습니다. 220개의 테스트 코드를 작성 및 유지보수하며 **수동 전수 테스트 시간을 75% 단축**했습니다.
- Docker + gitlab-runner를 활용한 테스트 CI/CD 환경 구축 경험이 있으며, 테스트를 제품 관리 프로세스에 정착시킨 경험이 있습니다.
- **BackstopJS를 활용한 시각적 회귀 테스트를 gitlab-runner 파이프라인에 연동**해 500여 개의 Storybook story를 자동으로 검증하며 안정적인 마이그레이션을 진행했습니다.

**AI**

- **Cursor Agent와 Claude Agent를 개발 프로세스에 적극 도입**하여 팀 생산성을 높이는 워크플로우를 구축한 경험이 있습니다. 단순 코드 생성을 넘어 Agent가 특정 역할을 맡는 방식으로 활용합니다.
- **MCP(Model Context Protocol) 서버를 직접 설계 및 운영**했습니다. 제품의 기능 명세, 코드 컨벤션, 테스트 시나리오를 MCP 서버에 컨텍스트로 주입하여, 각 기능 담당자가 AI의 도움을 받아 테스트 코드를 직접 작성하고 디버깅할 수 있는 환경을 구축했습니다.
- **Claude의 서브 에이전트(Sub-agent) 구조를 활용한 Agent Teams 방식**을 실무에 적용했습니다. Emotion → Tailwind 마이그레이션 시 '컨벤션 분석 에이전트'가 기존 코드 패턴을 파악하고 그 결과를 '변환 에이전트'에 전달해 1차 마이그레이션을 수행하는 파이프라인을 구성, **한 달 분량의 작업을 2주 만에 완료**했습니다.
- Codex를 활용한 **자동 코드 리뷰 프로세스를 구축**했습니다. Codex가 팀의 코드 컨벤션과 잠재적 버그를 검토하도록 했고, 제품 기능을 빠르게 학습할 수 있도록 명세를 트리 형태로 구조화해 **UI-코드-기능을 연결 지어 리뷰**할 수 있었습니다.
