- `page router`로 구현된 제품을 **`app router`로 부분 마이그레이션**했습니다.
- **RSC(서버 컴포넌트)와 클라이언트 컴포넌트의 경계를 설계**하고, **서버 prefetch 구조를 도입**했습니다.
  - 그 결과 **초기 로딩 속도(FCP)를 60% 개선**했습니다.
- 기존 `React-Query` 기반의 데이터 페칭 계층을 서버 컴포넌트 환경에 맞게 재설계했습니다.
- 점진적 전환이 가능하도록 마이그레이션 순서와 기준을 정의하고, 문서로 남겨 팀원들이 동일한 방식으로 작업할 수 있게 했습니다.
- `Codex`를 활용한 **자동 코드 리뷰 프로세스를 구축**해, 전환 과정에서 코드 컨벤션과 잠재적 버그를 검토했습니다.
